Entity Relationship Diagram
Database schema for the Aadhaar-based Unified EMR System
PATIENT
PK aadhaar_number (CHAR 12)
full_name VARCHAR(100)
date_of_birth DATE
gender ENUM
blood_group VARCHAR(5)
mobile VARCHAR(15)
email VARCHAR(100)
address TEXT
allergies TEXT
created_at DATETIME
HOSPITAL
PK hospital_id INT AUTO
hospital_name VARCHAR(100)
registration_no VARCHAR(50)
city VARCHAR(50)
state VARCHAR(50)
contact VARCHAR(15)
email VARCHAR(100)
type ENUM
is_active BOOLEAN
DOCTOR
PK doctor_id INT AUTO
FK hospital_id → HOSPITAL
doctor_name VARCHAR(100)
specialization VARCHAR(50)
qualification VARCHAR(100)
license_no VARCHAR(30)
contact VARCHAR(15)
MEDICAL_RECORD
PK record_id INT AUTO
FK aadhaar_number → PATIENT
FK hospital_id → HOSPITAL
FK doctor_id → DOCTOR
visit_date DATE
visit_type ENUM
department VARCHAR(50)
diagnosis TEXT
prescription TEXT
follow_up_date DATE
created_at DATETIME
LAB_REPORT
PK report_id INT AUTO
FK record_id → MEDICAL_RECORD
FK aadhaar_number → PATIENT
test_name VARCHAR(100)
result TEXT
normal_range VARCHAR(50)
report_date DATE
file_path VARCHAR(255)
ACCESS_LOG
PK log_id INT AUTO
FK aadhaar_number → PATIENT
FK hospital_id → HOSPITAL
accessed_by VARCHAR(100)
access_time DATETIME
purpose VARCHAR(100)
ip_address VARCHAR(45)
Relationships:
PATIENT (1) ──── (∞) MEDICAL_RECORD  |  HOSPITAL (1) ──── (∞) MEDICAL_RECORD  |  DOCTOR (1) ──── (∞) MEDICAL_RECORD  |  MEDICAL_RECORD (1) ──── (∞) LAB_REPORT  |  PATIENT (1) ──── (∞) ACCESS_LOG  |  HOSPITAL (1) ──── (∞) DOCTOR
